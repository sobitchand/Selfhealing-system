HTML Classes, IDs, and Path Classes

This demo shows how CSS targets standard classes, specific IDs, and vector path classes inside SVGs.

1. Reusable Button Classes

Classes (.class-name) allow you to apply the same styling rules to multiple elements.

2. Unique Element ID

IDs (#id-name) are used to target a single unique element on the page.

3. SVG Path Classes

Classes can be attached directly to <path> elements inside an SVG to style specific vector shapes.
